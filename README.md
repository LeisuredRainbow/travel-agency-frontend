# Travel Agency SPA

Single Page Application for the Travel Agency API.
Built with React, TypeScript, TanStack Router, TanStack Query, and Tailwind CSS.

## Features
- CRUD operations for Tours, Hotels, Guides, Clients, and Bookings.
- Display of OneToMany and ManyToMany relationships.
- Async confirmation UI for bookings.
- Responsive dark theme.

## Local Development
\`\`\`bash
npm install
npm run dev
\`\`\`

## Build
\`\`\`bash
npm run build
\`\`\`

## Production
The SPA is deployed on Render as a Static Site:
